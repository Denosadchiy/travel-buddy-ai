## 2. Кнопка «Cancel» работает мгновенно

- [ ] Открыть экран поиска отелей → кнопка **Cancel** видна сразу (во время анимации загрузки)
- [ ] Нажать Cancel → страница немедленно закрывается, возвращается предыдущий экран
- [ ] После Cancel предыдущий экран полностью интерактивен (тапы работают, анимация остановлена)
- [ ] В сетевом инспекторе браузера запрос к `/api/trips/{id}/plan` прерван (статус **canceled**)

## 3. Навигация во время загрузки

- [ ] Нажать кнопку «Назад» браузера во время загрузки → переход назад, нет зависания
- [ ] Закрыть вкладку во время загрузки → нет утечки задачи на сервере (проверить логи бэкенда: строка `"client disconnected, cancelling search task"`)
- [ ] Открыть другую страницу приложения во время загрузки → переход работает, нет белого экрана

---

## 4. Обработка ошибок сети

- [ ] Отключить сеть до начала поиска → сразу показывается сообщение об ошибке (не зависание)
- [ ] Отключить сеть в середине загрузки → через ≤75 секунд появляется timeout-ошибка "Request timed out..."
- [ ] Восстановить сеть → кнопка «Try Again» работает, новый запрос отправляется
- [ ] Network Link Conditioner: установить «Very Bad Network» → поиск завершается с ошибкой, не зависанием

---

## 5. Timeout (75 секунд)

- [ ] Заблокировать бэкенд (mock возвращает ответ через 80 секунд) → через ≤75 с показывается ошибка "Request timed out..."
- [ ] После timeout-ошибки кнопки «Go Back» и «Try Again» доступны и работают

---

## 6. Повторный запуск поиска (Retry)

- [ ] Нажать «Try Again» после ошибки → новый запрос отправляется (проверить в Network tab)
- [ ] Нажать «Try Again» 5 раз подряд быстро → только 1 активный запрос в каждый момент (нет дублирования)
- [ ] Прогресс-бар сбрасывается до 0% при каждом retry

---

## 7. Прогресс-бар и анимация

- [ ] Прогресс-бар не превышает 90% до получения реального ответа
- [ ] После успешного ответа прогресс-бар моментально переходит до 100%
- [ ] Навигация на страницу результатов происходит через ~400 мс после 100%
- [ ] Иконки-шаги (MapPin, Route, Utensils...) циклично переключаются во время загрузки
